# CRM Facebook - Minimal Flask Demo

Ứng dụng mẫu CRM quản lý khách hàng Facebook.

Yêu cầu:
- Python 3.8+

Cài đặt và chạy:

```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Mở trình duyệt `http://127.0.0.1:5000`

Ghi chú:
- Trang `Settings` (trang "đatabase con") quản lý cặp key/value cấu hình.
- Có placeholder để tích hợp import từ Facebook (API) sau này.
